Privacy Policy

Effective date: 30 October 2026

This policy explains what data Toon Studio Uploader (our TikTok developer app), the Lantern Tales channel and this website handle, and why. In short: the only TikTok account connected to the tool is the channel owner's own account, and the tool uses it only to upload the channel's videos to the owner's inbox.

1. Who connects to Toon Studio Uploader

Toon Studio Uploader is an internal tool. The only TikTok user who connects to it is the channel owner. The owner signs in through TikTok Login Kit (OAuth 2.0 with PKCE) and grants a single permission: video.upload. The tool does not request any other scope.

2. Data we receive from TikTok

When the owner authorizes the app, TikTok returns:

  • an access token and a refresh token;
  • the owner's open_id (an app-specific account identifier);
  • the list of scopes that were granted.

We do not receive or store the owner's TikTok password. We do not read profile information, followers, videos, comments, messages, or any data about other TikTok users.

3. How we use it

Tokens are used for two things only:

  • sending a video file created by the channel to the owner's TikTok inbox;
  • checking the status of that upload.

The tool does not post automatically. The owner reviews each draft and posts it manually in the TikTok app.

4. How we store it

  • The refresh token is stored as an encrypted secret in GitHub Actions, where the production system runs.
  • If updating that secret fails, a backup copy of the latest tokens (refresh token, access token, expiry time and granted scopes) is saved in the owner's private GitHub repository, encrypted with AES-256-GCM. The encryption key is kept separately as another encrypted secret.
  • Otherwise, access tokens are short-lived and are only held in memory while a job runs.

5. Sharing

We do not sell, rent or share TikTok data with anyone, and we do not use it for advertising or profiling.

6. Other services the system uses

The production system uses the services below to make videos. None of them receive TikTok user data or tokens.

  • Google Gemini API to write and check scripts and to generate voice-over.
  • Cloudflare Workers AI to generate background images.
  • GitHub to host the code and run the system (GitHub Actions).
  • Telegram to send finished clips and notifications to the owner.

7. Revoking access and deleting data

The owner can revoke the app's access at any time in the TikTok app, under the privacy or security settings that list connected apps and services (for example, Settings and privacy, then Security and permissions, then Apps and services; menu names may vary by app version). You can also email us to ask for deletion.

Stored tokens are deleted within 30 days after access is revoked or after the tool is no longer used.

8. People who watch our videos

The tool and this website do not collect any data about people who watch, like or comment on our videos. Your activity on TikTok is handled by TikTok under the TikTok Privacy Policy.

9. This website

This website uses no cookies, no analytics and no tracking scripts. It is hosted on GitHub Pages, and GitHub may keep technical logs such as IP addresses for security, under GitHub's own privacy statement.

10. Age

The channel and the tool are not directed at anyone under 18, and we do not knowingly collect data from minors.

11. Changes to this policy

We may update this policy. The new version will be posted on this page with a new effective date.

12. Contact
